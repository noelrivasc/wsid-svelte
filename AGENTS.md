# Agent behavior

Start at [`docs/agents/index.html`](docs/agents/index.html) — it links out to the rest of the documentation set under [`docs/`](docs/index.html).

At minimum, read these before touching code:

- [`docs/layout.html`](docs/layout.html) — code layout and where each kind of file belongs.
- [`docs/styling.html`](docs/styling.html) — theming, project tokens, Flowbite conventions.

## File and directory paths

Before creating files or directories, verify the target path against the layout conventions. If the path (even if provided by the user) does not match the conventions, suggest the correct path and confirm before proceeding.

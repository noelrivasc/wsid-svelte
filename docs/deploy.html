Deployment

Single Ubuntu VM, Docker Compose, Traefik for HTTPS, GitHub Actions for push-to-deploy. Brief downtime on each deploy is accepted.

Host setup (one-time)

  1. Install Docker Engine (28.x, see caveat below) and the Compose plugin from Docker's official apt repo — not the distro package.
  2. Create a non-root deploy user in the docker group.
  3. Disable SSH password auth (/etc/ssh/sshd_config.d/99-hardening.conf). Keep root login key-only.
  4. ufw: allow 22/tcp, 80/tcp, 443/tcp; default deny incoming.
  5. Point app DNS (and any add-on subdomains) at the VM's IP before first deploy — Let's Encrypt HTTP-01 needs it.
  6. Create /srv/wsid/, owned by deploy. Clone the repo there.

Per-environment files

  • .env — secrets and per-host config. See env vars.
  • ./data/ — SQLite file lives here; bind-mounted into the app container.
  • ./letsencrypt/ — Traefik's ACME state.

Compose profile

docker compose --profile prod up -d --build

Services: traefik (binds 80/443, mounts Docker socket read-only, Let's Encrypt resolver) and app (built from the repo's Dockerfile, Traefik-labelled for the app host). All on a single web network. Restart policy unless-stopped.

Boot sequence (inside the app container)

docker/entrypoint.sh runs:

  1. Snapshot the SQLite file (timestamped .bak).
  2. node /app/build/cli.mjs migrate — idempotent; only applies pending migrations.
  3. exec node ./build/index.js — adapter-node server on :3000.

Push-to-deploy

.github/workflows/deploy.yml SSHes into the VM on push to main and runs:

cd /srv/wsid && git reset --hard origin/main && docker compose up -d --build

Compose rebuilds the image, swaps the container, the entrypoint runs migrations, server boots. Downtime: a few seconds.

Required GitHub secrets: SSH_HOST, SSH_USER (deploy), SSH_KEY.

Manual ops against prod

SSH to the host, then:

cd /srv/wsid
docker compose exec app wsid migrate:status     # or any other CLI command
docker compose logs -f app                       # tail logs

Known caveats

  • pnpm + native modules. Allowlist better-sqlite3 in pnpm-workspace.yaml (allowBuilds:) or the install step skips native bindings and the app fails to load the module.
  • Docker Engine 29.x. Raises the minimum API version above what Traefik's bundled Docker client (even v3.5) advertises. Pin to docker-ce 28.x until Traefik bumps its client.

Backups

The DB is a single file. Copy it. The entrypoint already snapshots before migrations. For off-host backups, sync ./data/ to object storage on a cron.

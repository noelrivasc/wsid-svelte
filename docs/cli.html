CLI

Admin and ops commands. One source, two invocation paths — same code in dev and prod.

Source

Defined in src/cli/index.ts using citty. Bundled by esbuild into build/cli.mjs as part of pnpm build. Imports $lib/utils/config.runtime (never config.ts — $env/dynamic/private isn't available outside SvelteKit).

Build pipeline

flowchart LR src["src/ (TS)"] vite["vite build"] esbuild["esbuild"] server["build/ SvelteKit server"] clibundle["build/cli.mjs"] image["Docker image (node:22-alpine)"] entry["entrypoint.sh: migrate → server"] src --> vite --> server --> image src --> esbuild --> clibundle --> image image --> entry

Two ways to invoke

Form Underneath When
pnpm cli <cmd> tsx against TS source; host DB Bare pnpm dev flow; shares state with the running dev server.
pnpm cli:docker <cmd> docker compose exec app node /app/build/cli.mjs When the Docker stack is up (dev:docker or prod). Runs the exact bundle that ships.

Inside the container, wsid <cmd> is a shorter alias. Run with docker compose exec app wsid <cmd>

Commands

Command What
migrate Apply all pending migrations. Idempotent; also runs at container boot via the entrypoint.
migrate:status List each migration as applied (with timestamp) or pending.
migrate:down Roll back the most recent migration.

Shortcuts: pnpm migrate ≡ pnpm cli migrate; pnpm migrate:docker ≡ pnpm cli:docker migrate.

Adding a migration

  1. Drop src/lib/store/migrations/YYYY-MM-DD-<name>.ts exporting up / down.
  2. Register it in src/lib/store/migrations.bundled.ts — the key MUST match the filename stem (kysely persists it in kysely_migration).
  3. Rebuild the image before invoking via :docker: pnpm dev:docker --build.

Adding a command

Add a defineCommand block in src/cli/index.ts and register it under subCommands. Reuse the same DB/config wiring the existing commands use.

Why bundle

The runtime image is plain node:22-alpine — no tsx, no pnpm. Bundling to a single .mjs means prod runs vanilla node, the same way SvelteKit's server does. See Docker setup for the bigger picture.

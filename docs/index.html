How the app is built

Stack What each tool does and why it's in the tree (SvelteKit, Vite, Tailwind, Zod, Kysely, SQLite, better-auth, Storybook, Vitest).
Code layout & conventions Where things go. Each concern has one predictable home; routes are thin glue.
DB & storage SQLite + Kysely, bundled migrations, one repository per entity, import rules between store and engine.
Event sourcing How a Decision is derived by replaying its action log.
Auth Magic-link auth via better-auth: routes, session, mailer, GET-then-POST flow.
Styling & theming Tailwind v4 @theme tokens, Solarized palette, shared CSS between app and Storybook.
Storybook Component sandbox, story format, and the patterns that keep components renderable in both SvelteKit and Storybook.
Storybook-compatible forms The mockSubmit prop that lets a form post to a real SvelteKit action in the app but intercept and cancel it in Storybook.
Testing Two vitest projects (Node + browser), Storybook integration, where tests live.

Ops

CLI Admin commands (migrate, migrate:status, ...) — same code path local and in container.
Deployment Single-VM Docker Compose + Traefik + Let's Encrypt + GitHub Actions push-to-deploy.

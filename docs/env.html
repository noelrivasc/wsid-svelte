Every variable the app reads. All access goes through src/lib/utils/getConfig.ts — nothing else touches process.env or $env/*.

Two config wrappers, one source

getConfig.ts is a pure factory: getConfig(env). It's wrapped twice so SvelteKit and CLI scripts can each pass the right env source:

  • src/lib/utils/config.ts — wraps $env/dynamic/private. Used by SvelteKit server code.
  • src/lib/utils/config.runtime.ts — wraps process.env. Used by the CLI and any tsx script.

Inside SvelteKit code, always import from $lib/utils/config. Inside CLI code, import from $lib/utils/config.runtime. The two never mix.

Local .env

.env is gitignored. Copy .env.example when starting. The pnpm cli / pnpm migrate scripts pass --env-file-if-exists=.env to tsx; SvelteKit/Vite auto-loads it in dev and build.

Dev setup (Vite)

Fast inner loop: SvelteKit's dev server against a host-side SQLite file. No Docker required.

Prerequisites

  • Node 22+ and pnpm (corepack or global install).
  • For magic-link auth in dev, a local SMTP catcher — see mailpit below; it's the one Docker piece the bare flow benefits from.

First run

pnpm install
cp .env.example .env        # adjust if needed
pnpm migrate                # creates data/wsid.db, applies migrations
pnpm dev                    # http://localhost:5173

Daily commands

Command What it does
pnpm dev Vite dev server with HMR.
pnpm check svelte-check + TypeScript across the project.
pnpm test Vitest (both Node and browser projects). See testing.
pnpm lint / pnpm format Prettier + ESLint.
pnpm storybook Storybook on :6006.
pnpm docs Serve these docs on :8081 (python3 http.server).
pnpm cli <cmd> Run the admin CLI against the host DB (tsx). See CLI.
pnpm migrate Shortcut for pnpm cli migrate.
pnpm cli seed Seed sample data (idempotent).

Where the DB lives

The dev DB path comes from DATABASE_PATH (see env vars), defaulting to data/wsid.db. It's gitignored. Delete the file to start fresh; pnpm migrate will rebuild it.

When to switch to Docker

Use the Docker setup when you need to: validate native-build paths (better-sqlite3 binaries differ on alpine), test the entrypoint's migrate-on-boot behaviour, or exercise the bundled CLI (cli.mjs) the way prod does.
